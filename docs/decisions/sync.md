# Sync between devices: removed

**Removed 2026-11-19** (Melvin: "i want to completely deprecate google drive sync", and "dont bother with google drive migration, i dont have any customers"). Sync through a file in the person's Google Drive is gone, with no import: the backup in the Tuned account does the same job ([accounts](accounts.md)). Gone with it: `data/GoogleDrive`, Google's sign-in with a code, the "Tuned sync" file, `core/PassphraseCrypto` (which only opened copies older versions had locked), Restore from Google Drive on the welcome screen, and the `GOOGLE_TV_CLIENT_ID` and `GOOGLE_TV_CLIENT_SECRET` secrets. The "TVs and Limited Input devices" OAuth client in Google Cloud can be deleted.

What carried over unchanged into the backup: what the copy holds (`SyncCopyRepository.syncCopy`, everything the person set up, Melvin 2026-11-19: "It should save All possible settings"), the device-only settings that never travel, the whole copy with the newer change winning (`core/CloudSync.decide`), and running when the app opens and when it leaves the screen (`work/CloudSyncWorker`).

History, for anyone who wonders why it was built this way: Melvin first chose his Google account over a Tuned server (2026-11-17) so there was no server to run, then dropped the passphrase (2026-11-18: "i dont think we need encryption"). Google's sign-in with a code refused the hidden app folder (`drive.appdata`, "Invalid device flow scope"), so the copy was a visible file under `drive.file`. Once Tuned had its own server for Premium seats and TV sign-in, the account replaced it.
