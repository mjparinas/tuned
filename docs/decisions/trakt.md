# Trakt

From the app audit, Melvin picked Trakt (item 14): what's watched in Tuned shows up in the person's Trakt history and "up next", alongside every other app they use.

**Signing in** (`data/TraktAccount`). Trakt's device code: Settings › Playlists and account › Connect Trakt shows a short code and trakt.tv/activate, which works the same from a phone, a computer or a TV remote, and Tuned never sees the Trakt password. A button beside the code copies it, for pasting on trakt.tv/activate when that's open on the same phone (Melvin, 2026-11-18); the Google Drive sign-in code has the same button (`ui/settings/SignInCode`). The dialog asks Trakt every few seconds (slower when Trakt says so) until the code is entered, refused or runs out. The tokens are sealed with a key in the Android Keystore (`data/KeystoreBox`), like the login, and are never synced. They are renewed a day before they expire; if Trakt no longer accepts them (revoked on trakt.tv), Tuned signs out of Trakt too. Disconnecting tells Trakt to drop the token.

**Scrobbling** (`player/TraktScrobbler`, `core/Trakt`, with tests). Films and episodes only: start when one plays, pause when the person pauses (buffering isn't a pause), stop when it ends, the next one starts or the player closes, each with how far through it is (for Next, how far the last one got, not where the next one starts). Trakt marks it watched from 80%. Trakt matches by title and year (films) or show title and year with the season and episode number, so no TMDB key is needed; names are cleaned of the provider's tags the same way as for ratings. Live TV, catch-up and recordings aren't sent. While casting, the spot comes from the TV, not the phone's stopped player. A pause or stop at 0% isn't sent, since there is nothing to save and Trakt turns it down (HTTP 422, 2026-11-18). A failed send is logged with Trakt's answer and dropped; the next play or pause sends the state again. Settings › Playlists and account › Scrobble what you watch turns it off without disconnecting (on by default).

**The app's keys.** Trakt identifies the app by its client id alone: it stopped issuing client secrets (new apps sign in with PKCE or a device code, and `client_secret` is optional and deprecated on every `/oauth` call), so Tuned sends none (Melvin's Trakt app, 2026-11-18, shows "Client Secret: Not issued"). The id comes from the release workflow's secret `TRAKT_CLIENT_ID` into `BuildConfig` and is never committed. A build without it (debug builds, pull requests) hides everything Trakt.
