# Play Console foreground-service demo videos

Unlisted YouTube links go in Play Console › App content › Foreground service permissions.

| File                     | FGS type       | What it shows                                                          |
| ------------------------ | -------------- | ---------------------------------------------------------------------- |
| `fgs-data-sync.mp4`      | Data sync      | Settings › Guide and refresh › Refresh now, then the sync notification |
| `fgs-media-playback.mp4` | Media playback | Playing a demo channel, Home (background / PiP), media notification    |

Recorded on an emulator with the public review playlist (`https://www.tunedplayer.com/review/playlist.m3u`). No real provider names.

Upload each as an **unlisted** YouTube video, then paste the URLs into the Console form.
