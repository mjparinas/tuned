Tuned 1.2 adds tablet layouts, Skip intro, Watch later, subtitle timing, language filters and a channel scan that hides channels that never play.

## New

- Hide channel groups
- Adjust subtitle timing in the player
- Tag releases with the plain version, no build number
- Watch later list and mark as watched
- Make pull to refresh a setting, off by default
- Filter channels by language
- Show brightness and volume as edge bars while swiping
- Show new episodes since a show was last opened
- Skip intro on episodes, learned per show
- Scan channels and hide the ones that keep failing, with a health report
- Tablet layouts with a navigation rail, side-by-side panes and the guide beside the player
- A favourite heart on every channel row, readable film pages and titles without language tags
- Hide empty event channels ("no event streaming") by default

## Fixed

- Offer new releases while Tuned stays open, and add Check for updates
- A close button and tap-outside to put the player's channel guide away
- Keep search and lists working while the guide or playlist refreshes
- Tapping the cast button no longer crashes the player
